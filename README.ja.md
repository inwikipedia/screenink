# ScreenInk 画面注釈

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Windows 向けの単一ファイル画面注釈 / お絵かきツールです。純 Rust + [`windows-sys`](https://crates.io/crates/windows-sys) で実装し、全画面オーバーレイを自前描画します。サードパーティ製 GUI フレームワーク不要、インストール不要で、exe ひとつでそのまま動きます。

![ScreenInk プレビュー](preview.png)

## 機能

- **全画面オーバーレイ注釈**：仮想デスクトップ全体をカバー（マルチモニター対応）。下のウィンドウの操作を妨げません
- **7 つのツール**：フリーハンドペン、直線、四角、楕円、矢印、テキスト、消しゴム
- **8 色 × 太さ 3 段階**。テキストは文字サイズ 3 段階、`Ctrl+V` での貼り付けに対応
- **元に戻す / やり直し / クリア**、履歴は最大 50 ステップ
- **画面固定（F）**：静止画をキャプチャしてその上に注釈。動いている画面の解説に便利
- **マウス透過モード（M）**：下のアプリにマウス操作を戻します。グローバルホットキーまたはツールバーでいつでも復帰可能
- **7 言語 UI**：English、简体中文、繁體中文、日本語、Deutsch、Español、Français。起動時に Windows の言語を自動判定（未対応なら英語にフォールバック）。ツールバーの言語ボタンでいつでも切替できます
- **ワンクリックで PNG 保存**：デスクトップにタイムスタンプ付きファイル名で保存
- **単一ファイル・CRT 静的リンク**：VC++ ランタイム不要、小型でコピーしてすぐ使える

## ショートカット

| 分類 | キー | 機能 |
| --- | --- | --- |
| ツール | `P` `L` `R` `O` `A` `T` `E` | ペン / 線 / 枠 / 円 / 矢印 / 文字 / 消去 |
| 色 | `1` – `8` | 8 色を切替 |
| 太さ | ホイール または `[` `]` | 細く / 太く |
| 編集 | `Ctrl+Z` / `Ctrl+Y` / `C` | 元に戻す / やり直し / クリア |
| ファイル | `S`（または `Ctrl+S`） | PNG をデスクトップに保存 |
| 表示 | `F` | 画面の固定 / 解除 |
| 透過 | `M` | マウスモード切替 |
| 復帰 | `Ctrl+Alt+M` / `Ctrl+Alt+N` | 透過モードから描画に戻るグローバルホットキー |
| その他 | `H` / `F1` | ヘルプカードの表示切替 |
| その他 | `Tab` | ツールバーの表示切替 |
| テキスト | `Enter` / `Esc` / `Ctrl+V` | 確定 / 取消 / 貼り付け |
| 言語 | ツールバーの言語ボタン | 7 言語を順番に切替 |
| 終了 | `Esc` | プログラムを終了 |

## 使い方

`ScreenInk.exe` をダブルクリックすると画面への注釈を開始できます。終了は `Esc`。保存画像は**デスクトップ**に `ScreenInk_20261105_173000.png` のような名前で出力されます。

## ソースからビルド

Rust ツールチェーン（MSVC ターゲット）が必要です。

```bash
cargo build --release
```

成果物は `target/release/screenink.exe`（リポジトリ直下の `ScreenInk.exe` はリネームしたコピー）。`.cargo/config.toml` で `+crt-static` による CRT 静的リンクを有効化し、release プロファイルはサイズ重視（LTO + `opt-level="z"` + `strip`）です。

描画パイプラインのセルフテスト（ウィンドウを出さず `selftest.png` を出力。7 言語すべてのツールバーを含む）：

```bash
cargo run -- --selftest
```

## プロジェクト構成

| ファイル | 役割 |
| --- | --- |
| `src/main.rs` | ウィンドウ作成、メッセージループ、グローバルホットキー、操作の統括 |
| `src/i18n.rs` | 言語 enum と 7 言語の文字列テーブル |
| `src/ui.rs` | 自前描画のトップツールバーとヘルプカード |
| `src/raster.rs` | ピクセルバッファ、キャンバス、図形のラスタライズ |
| `src/capture.rs` | 画面キャプチャ（固定用の背景） |
| `src/text.rs` | テキスト描画（言語ごとのフォント切替） |
| `src/png.rs` | PNG エンコードと保存 |
